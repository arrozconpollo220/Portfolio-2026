# Portfolio 2026 ✨

A modern, dynamic, and sleek portfolio website built with HTML5, CSS3, and JavaScript.

## 🌟 Features

- **Modern Design**: Dark theme with stunning purple-to-pink gradient accents
- **Responsive**: Works perfectly on mobile, tablet, and desktop devices
- **Animated**: Smooth animations, morphing shapes, and scroll-triggered effects
- **Interactive**: Smooth scrolling, mobile menu, and dynamic content
- **Fast**: Pure vanilla JavaScript with no dependencies

## 🚀 Quick Start

1. Clone this repository
2. Open `index.html` in your browser
3. That's it! No build process required.

For local development with live reload:
```bash
python3 -m http.server 8080
# Then open http://localhost:8080 in your browser
```

## 📝 Customization

### Personal Information

Edit `index.html` to update:
- Your name in the hero section (line 28)
- About section content (lines 61-73)
- Skills and technologies (lines 87-146)
- Projects (lines 155-242)
- Contact information (lines 257-274)
- Social media links (lines 276-278)

### Colors

Edit the CSS variables in `styles.css` (lines 13-20):
```css
--primary-color: #6366f1;
--secondary-color: #ec4899;
--dark-bg: #0f172a;
/* ... more colors */
```

### Fonts

Change the Google Font in `index.html` (line 10) and update the font family in `styles.css` (line 24).
